# XIVLauncher Odin Preview downloads

This repository hosts signed APK releases and update metadata for XIVLauncher Odin Preview. Development source is maintained separately.

Download **XIVLauncher-Odin-Preview.apk** from [Releases](https://github.com/codyavila/XIVLauncher-Odin-Releases/releases) and install it over the existing **XIVLauncher Odin Preview** app. Do not uninstall or clear app data. Compatible updates preserve settings, saved sign-in and runtime/game storage.

If your installed app still checks the old source repository, install an APK from here once using the Odin's browser. Then use **About → Launcher updates → Check for updates** for later releases. Android asks you to confirm installation.

Releases contain one APK, its SHA-256 checksum and `build-info.json`. The updater verifies the APK hash, package, newer version and retained signing certificate before installation.
